# Final AIO

![Build](https://github.com/iimik/final-aio/workflows/Build/badge.svg)
[![Version](https://img.shields.io/jetbrains/plugin/v/26415.svg)](https://plugins.jetbrains.com/plugin/26415)
[![Downloads](https://img.shields.io/jetbrains/plugin/d/26415.svg)](https://plugins.jetbrains.com/plugin/26415)

Final AIO 是一个 IntelliJ IDEA 插件，  
提供一组**相互独立但可组合使用的功能模块**，用于日常 Java 开发。

Final AIO is an IntelliJ IDEA plugin that provides a set of  
**independent but composable modules** for daily Java development.

---

## Modules

- Spring Module
- Tasks Module

---

## Spring Module

Spring 模块作用于 Spring / Spring Boot 项目，  
用于在 Controller 方法级别提供辅助操作。

Spring module works with Spring / Spring Boot projects  
and provides method-level helper actions.

**SEE:** [`Spring Feign Navigator ｜ final-aio-spring/README.md`](final-aio-spring/README.md)

---

## Tasks Module

Tasks 模块是官方 Task 插件的扩展模块，  
用于在代码与文档中识别 Task Reference，并提供跳转能力。

Tasks module extends the official Task plugin  
and adds navigation for task references in code and documents.

**SEE:** [`Task Mention｜final-aio-tasks/README.md`](final-aio-tasks/README.md)

---

## Notes

- 各模块可独立启用
- 所有功能均为 IDE 侧能力，不影响运行时行为

---

- Modules can be enabled independently
- All features are IDE-side only and have no runtime impact
